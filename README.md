# DAWNWARD — 攻撃をそらして灯を守る

夜の町の灯を、三つの駒で敵の攻撃から守る盤の上の戦術ゲーム。敵が次にどこを撃つかは全部見えているので、押す・壁を建てる・向きを変えるで攻撃をそらし、三つの刻を守り抜く。

## 遊び方

1. 赤い破線のマスは、このターンの終わりに **必ず** 攻撃される。そこにある灯は消える。このターンで消える灯・倒れる駒には二重丸が付く。
2. 三つの駒は、それぞれ 1 回動いて 1 回手を出せる（順番は自由）。
   - 鞠（丸）: 縦横 3 マス。隣のもの（敵・駒・壁）を 1 マス押す。押した先が塞がっていれば両方に傷 1。盤の外へ押し出した敵は落ちて消える。
   - 楯（四角）: 縦横 2 マス。隣の空きマスに壁を建てる（「移動 / 壁」を切り替える）。壁は攻撃を受け止め、裂の線を止め、敵の番の終わりに崩れる。
   - 梶（菱形）: 縦横 4 マス、駒の上を通り抜けられる。隣の咬・裂の向きを右か左へ 90 度回す。
3. 敵（夜のかたち）: 咬は向いた隣を噛む、裂は向いた方向を盤の端まで裂く（駒は素通り、壁で止まる）、弾は四方の隣を弾く。敵の攻撃は敵にも当たる。破線の丸は次の敵の番に敵が現れる印で、駒か壁で塞げば出てこない。
4. 決められたターンを耐えれば、その刻は勝ち。**灯を 1 つも消さずに守った刻には星**。盤の灯が全部消えるか、駒が全部倒れたら夜が終わる。
5. 宵・丑・暁の三つの刻を守り抜けば夜明け。宵と丑に勝つたびに強化を 3 つから 1 つ選ぶ。
6. 「確定」までは「一手戻す」で何度でも戻せる。敵の番は盤を押すと最後まで飛ばせる。

- 今夜: 端末の日付から盤が決まる（その日に最初に終えた 1 回を記録。続けて終えた日数も数える）。好きな夜: 毎回違う盤（結果に種が出る）。
- 手引き: 5 講で駒の使い方を 1 つずつ覚える。
- 途中で閉じても、確定したターンと選んだ強化のところから続きを遊べる。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node test.mjs                 # 決まりの自己チェック
node tools/balance.mjs        # 自動の打ち手で 200 夜ずつ回す（20 秒ほど × 3）
```

- `logic.js`: 決まり（盤・手・敵の番・盤の作り方・1 夜・保存の読み直し・手引き）。DOM に触らない。
- `main.js`: 画面・触り方・音・保存。
- `tools/balance.mjs`: バランスを測る開発用の道具（ページからは読まない）。

### バランス（2026-09-25）

町の灯を夜全体の体力にせず、刻ごとに「灯を 1 つも消さずに守れたか」で星を付ける形にした。
その代わり、刻の負けを「灯がいくつ消えたら」にして、自動の打ち手（1 ターン先だけを読む）で各 200 夜まわし、**夜明け率が 55〜70% に入る** 形を選んだ。

| 刻の負け | 夜明け | 星の平均 | 星 3 つの夜明け | 刻ごとの星（宵 / 丑 / 暁） |
|---|---|---|---|---|
| 灯 1 つで | 5% | 1.00 | 5% | 72% / 34% / 19% |
| 灯 2 つで | 30% | 1.22 | 6% | 69% / 41% / 17% |
| **全部消えたら（採用）** | **67%** | 1.23 | 6% | 69% / 41% / 18% |

- 丑・暁の耐えるターンは、企画の 5・6 から 6・7 に 1 ずつ足した（元の値では「全部消えたら」で夜明け 76% と目標を超えたため）。
- 決着が付かない夜（打ち切り）は 0。
- 自動の打ち手は弱い（駒どうしの連携が下手）ので、人の夜明け率はこれより高く、星のほうが目標になるはず。人にとっての難しさは測っていない。
